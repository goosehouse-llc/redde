# Contributing to Redde

Thanks for helping. Bug reports, fixes and ideas are all welcome.

## Before you open a pull request

- For anything bigger than a small fix, open an issue first so we can agree on the approach.
- Keep changes focused: one fix or feature per pull request.
- Run the tests (see "Tests" in the README) and say in the pull request how you checked the change.

## Contributor License Agreement

Every contributor needs to sign the [Contributor License Agreement](CLA.md) once. When you open your first pull request, a bot will comment with a sentence to reply with; reply with it and you're done, for that pull request and all future ones. You keep the copyright in your work; the agreement lets Goosehouse LLC keep offering Redde under its [license](LICENSE.md) and change or add license terms later.

Pull requests can't be merged until everyone who contributed to them has signed.
